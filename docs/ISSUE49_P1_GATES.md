## 2 门槛 2：面上自由项不是常数 0.5

半边探针：`quad(+h)` 与 `quad(-h)`，反对称部分给立体角比例 `c`，对称部分是主值。
平板双重体核关于 `h` 严格奇对称，**实测主值恒为 0（<1e-12）**，所以面上极限只剩 `c(x)*B(x)`。

| 配置点 | 预测 c | 外推 c | 最小 h 处 c | 与内置 -0.5 的差 | oracle self |
|---|---|---|---|---|---|
| 内部重心 | 0.500000 | 0.500000000 | 0.499998595 | 0.0000 | [-0.500, -0.000, -0.000] |
| 边中点 | 0.250000 | 0.249997760 | 0.249997438 | 0.2500 | [-0.500, -0.000, -0.000] |
| 直角顶点 | 0.125000 | 0.124997760 | 0.124997730 | 0.3750 | [-0.500, -0.000, -0.000] |
| 45 度顶点 | 0.062500 | 0.062499208 | 0.062499178 | 0.4375 | [0.000, -0.000, -0.500] |

预测值就是 `内角/(4*pi)`：内部 0.5、边中点 0.25、直角顶点 0.125、45 度顶点 0.0625。
**PR #52 oracle 的 self 分支把自由项写成常数 `-0.5*B`（等价 c=0.5，来自 -n 侧）**，只在光滑内部点成立；
节点式 P1 的配置点恰是顶点，那里偏大 4 倍（直角）到 8 倍（45 度）。

|---|---|---|---|---|---|---|---|
| dp_s020 | 1004 | 510 | 278 | 429 | 81 | 16 | 0.2343 - 0.5030 |

梯形翼的尖锐后缘节点装配出的 c 是 **0.2343 - 0.2969**（约 1/4），常数 -0.5 在这些节点上偏大 **1.7-2.1 倍**；
12290 面网格上这类节点有 55 个。光滑内部节点的装配值 0.5000008 - 0.5013，验证了 `sum(内角)/(4*pi)` 恒等式。

## 3 门槛 3：节点未知量、方程数、gauge 与切口

| 网格 | 重复节点组 | 原始边界边 | 合并后边界边 | 非流形边 | 闭曲面 | 需 gauge | 切口节点 |
|---|---|---|---|---|---|---|---|
| dp_s020 | 0 | 14 | 14 | 0 | False | True | False |
| dp_s014 | 0 | 20 | 20 | 0 | False | True | False |
| dp_s005 | 0 | 54 | 54 | 0 | False | True | False |

两条与实现直接相关的事实：

1. `surface.json` 的 `coordinates` 里含尾迹顶点：12290 面档有 **1212 个顶点不在壁面里**（7385 -> 6173）。
   节点未知量必须由壁面三角重建，按 `len(coordinates)` 开会多出 16.4% 的无声未知量。
2. 壁面是开曲面（只有后缘切口为边界，14/20/54 条边），所以常数 doublet 平移是零空间 → **必须 pin 一个 gauge**。
   三档都 `duplicated=0`、`split=0`、`nonmanifold=0`：这批 Gmsh 网格没有拓扑切开的共享节点，但这必须是**被检查**的，不能假定。

## 5 对下一步（连续 P1 wall solve）的硬约束

1. 对角/自由项必须**由装配的立体角算出**（逐面板 `c` 求和），不能写死 `-0.5`；否则后缘节点系统性错 1.7-2.1 倍。
2. 未知量集合必须从壁面三角构建并做重合点合并；尾迹顶点不得进未知量。
3. 开曲面必须有 gauge（常数平移），并在残差里按投影消掉。
4. 以上是**几何/核级**结论；与解析球对比、以及真正的 P1 wall solve 仍未做。
