## 2. 测试：12 passed（附沙箱例外）

直接跑 `pytest` 得到 **11 passed / 1 error**，error 是环境问题不是物理问题：

    E  PermissionError: [WinError 5] ... 'runs\pr29_git\pytest-of-vault'
       at _pytest/pathlib.py:175 os.scandir(root)

本机 DSH Windows 文件沙箱**不允许枚举**任何 `pytest-of-*` 目录（该目录 pytest 自己刚建好也
立刻不可列；同进程先建后列的普通目录可以，换名/换 mode 都可复现），因此 `tmp_path` 的
编号目录机制无法工作。已排除的替代方案：全新 `TMP`/`TMPDIR`、显式 `--basetemp`、预先建目录、
跨进程预建目录——全部同样 `WinError 5`；纯 Python 先建后列同一路径则正常。

为让**被测代码原样**跑完，用一个位于仓库外的本地插件 `runs/dsh_tmp_plugin.py` 提供等价的
`tmp_path`（只是一个已存在的可写目录），不改 PR 的任何文件、不改断言、不把 skip 当通过：

    python -m pytest -q -p dsh_tmp_plugin test/test_pressure_recovery_ab.py \
        test/test_pressure_recovery_half_integration.py   ->  12 passed in 3.56 s (EXIT=0)

## 4. 判读

1. **候选不是控制的相容细化**。同一冻结势场、两个都自洽的恢复算子，最大 Cp 差随网格
   3.31 → 8.62 → 22.76 单调放大；控制组角点尖峰随网格单调加深（-4.03 → -9.79 → -15.62），
   候选则非单调（-1.91 → -1.35 → -23.26）。两者在 h→0 时并不收敛到同一个值，
   因此不能用「候选更平滑/更小」来论证它更正确。
2. **近场 CD_p / CM_y 不是离散势场的良定义泛函**。只换恢复算子，CD_p 变 +163%…+196%、
   CM_y 变 -47%…+58%，而 CL 只变 0.8%…1.5%（CL 由环量主导，不经过角点）。这正是
   「近场 CD 是相消残差」的机制层面证据：净值只占毛值的 5–13%，角点一项就能把它翻倍。
3. **不影响 #28 的结论**。#28 的尾迹双侧读数在完整镜像场上做，不经过壁面角点恢复；
   两者的证据链互相独立。
4. **不建议进入实施 PR**，也不移植 JAX/Torch 可微版本。基线（原面心仿射 QR）保留。

## 5. 可证伪假设与下一步单变量实验

- H：翼梢后缘角点的 Cp 尖峰是**几何角点奇性**（两个面法向不连续 + 势在角点不可微），
  不是任何一个恢复算子的实现 bug。
- 可证伪点：把角点区域从载荷积分中排除（或换一档更细网格只看角点邻域），两个算子的
  载荷差应当同步缩小到 <5%；若仍相差 >100%，则假设被推翻。
- 单变量实验：396/1205/1966 各跑一次「角点邻域 3 环内面片标记 + 单独积分」，其余完全不变；
  同时输出角点邻域内两种 Cp 的逐面差与被排除的面积占比。
