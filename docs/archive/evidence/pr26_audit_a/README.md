## 3. 三条硬事实

### 3.1 毛值几乎不动，净值涨 175%

Σ|Cd| 从 `0.115508` 到 `0.129936`（+12.5%），净 CD 从 `0.006168` 到 `0.016968`（+175%）。**净/毛 从 5.3% 升到 13.1%。** 也就是说：细分 11 倍并没有让"两项大数相减"变好，只是把残差从 5% 抬到 13%。近场 CD 在这条路径上是一个**相消残差**，不是被解析出来的物理量。

### 3.2 机翼分量在粗网格上贡献负阻力

分量 30（机翼，244 面）在 396 上是 **−0.00063795**，在 4371 上是 **+0.00841186**；分量 20（机身，152→542 面）从 `+0.00681` 到 `+0.00856`。机翼净阻的绝对值只有它自身毛值（0.0878→0.0999）的 **0.7%→8.4%**。**净 CD 的增长几乎全部来自机翼残差项，而不是机身。**

### 3.3 理想 Trefftz 估计器自洽，近/理想的比值增长完全由近场驱动

`CDi/CL_Γ²` 在 5 档上恒为 `0.07719 / 0.07707 / 0.07715 / 0.07780 / 0.07701`（±0.5%）。理想 Trefftz 就是一个 `K·CL²` 的标度律，档间只随 CL 变化（+11.8%）；近/理想比值 0.2684→0.5924 的增长几乎全部来自近场 CD（+175%）。**不能用"近场追上理想"当作收敛证据。**

### 3.4 尾迹部分只有来流通量，没有总流信息

5 档 `rms|U∞·n|/U = 0.08715574274765817` 完全相同（= sin 5°）。审计器自己标了 `test_type=freestream_flux_only_not_full_local_wake_tangency`。**这不是总流残差，也不能回答"尾迹是否与当地流动相切"。**

## 4. 云端要求第②项：当前拿不到，原因是结构性的

要求的三个量（实际总流 `V_mean·n`、材料环量输运 `V_mean·grad(Γ)`、两侧 `ΔCp`）**目前对半模 wingbody 无法输出**，原因不是没跑，而是：

- 唯一实现这三项的 `panel/audit.py`（本轮尾迹工作新增）读取的是**全表面** `panel/solve.py` 的 run 目录：`surface_input.json` + `result.json` + `fields.npz`，其中 `fields.npz` 必须含 `wake_basis`/`wake_slope`（材料标签）、`wake_linear_direction`、`neighbor_indices`/`panel_x_dir`、`cut_face_pairs` 等字段。
- 半模 `half_native` 路径**不写这些字段**，也没有镜像展开后的全表面布置。两者 schema 不同（`dpanel.half_planar_cut.v1` vs 全表面 run）。
- 因此我在 396/1205 上**没有任何总流尾迹数字可报**。宁可报缺口，也不拿 `U∞·n` 冒充总流残差。

**需要的只读前置件**（约 1 天，不改生产）：`panel/audit_half_wake.py` —— 用 `panel/verify_half_mirror` 已有的镜像展开（`y→−y`、Γ 偶对称）把半模解铺成全表面，重建 `wake_basis`/`wake_slope` 与 `cut_face_pairs`（`fixture` 里 `cut_edges`+`cut_kind` 已有），再调用现有 `core/triangle_kernel.influence` 的 0/1 阶基函数算三类残差。自检锚点：壁面 `|V·n|` 的 RMS 必须复现审计器的 `wall_normal_rms`，`1−|V|²` 必须复现 `Cp_raw`（现有 `panel/audit.py` 就是这么自检的）。

`physical_accuracy_accepted=false` 不变；近场 CD/CM 不进 GRASS 训练目标。
