## 结论（只陈述本实验测到的）

1. Gamma 分辨率解释掉 5 度 CL 差距的一半左右：12290 壁面 16 → 64 dof 使 CL_p 0.695979 → 0.700910（+0.71%），与 VSP panel 的差从 +1.24% 收到 +0.53%。

2. CL_p 与 CL_Gamma 的差不是 Gamma 分辨率造成的：同一细化下两者一起上升，相对差 +3.07% → +2.90% 基本不动，它属于压力恢复/离散化通道。

3. 0 度截距不是环量问题：0 度档 16 → 64 dof 只把 CL 从 0.194801 抬到 0.196217（+0.73%），对 VSP 厚 panel 的 0.222424 仍是 -11.8%。

4. Trefftz 诱导阻力对 Gamma 分辨率几乎不敏感：CDi 0.011327 → 0.011332（+0.04%），而近场 CD_p 0.001031 → 0.001333（+29%），再次说明近场压力阻力是正负相消残差。

5. TE 跳跃残差随 Gamma 细化单调下降：0.00604 → 0.00369（-38.9%），细化确实改善了 Kutta 条件的满足度。

6. Gamma(y) 的改动集中在翼尖：全体样本最大偏差 18.15% 在 y = 0.975，y < 0.9 段也有 7.53% 在 y = 0.899（都在翼尖收缩段），而除最外侧内部站位外其余 16 个原始站位偏差 ≤ 1.2%，Gamma_sum 只增 +0.44% → 细化修正的是翼尖卸载形状，不是整体环量水平。
