# 翼梢角点的载荷差异预算：不删面元、不替换物理解

关联 Issue #31、PR #29；基线 `856ed1ee2a70a5eaac136873ab08697fcdafb897`。
本研究不改变生产压力恢复、势方程、几何、尾迹、梯度或训练入口。

## 结论与边界

本地 PR29 验收在同一冻结势场上看到最大 Cp 差 3.31 / 8.62 / 22.76，
三档最坏点均接近翼梢后缘，而中位差减小。这个现象支持区域归因，但尚不能
推出连续压力载荷不存在、角点必然有不可积奇性，或任一重构已得到真值。

本程序将所有面元完整保留。所谓“球外”是贡献分解，不是删除角点后得到的
新阻力；不能将球外差低于5%当作物理验收。研究候选继续保留，不升级为默认。

## 方法

`panel.pressure_region_budget` 只读取 PR29 已有五个产物：

- `surface_input.json`、`frozen_state.npz`：同一离散几何和状态。
- `recovered_fields.npz`：原始及候选逐面 Cp。
- `patches.json`、`report.json`：原节点邻域及载荷记录。

没有 JAX / Torch / numba / Gmsh 依赖，不重新求解、重建网格或运行压力恢复。
输入只使用 NumPy，输出新目录。禁止覆盖之前的实验。

预先由真实CAD/后缘几何确定同一个特征点，坐标单位必须与 surface 相同；
不得跟着每档最大Cp位置移动点。默认 r/Cref = 0.025 / 0.05 / 0.1 / 0.2，
在查看该次结果前固定；可显式更改，但必须记录为不同实验。

对每个平面三角形计算到特征点的精确最小距离（面内垂足或边线段）和最大距离
（顶点）。每个半径将全部三角形划分为：

1. `inside`：整个面片在球内；
2. `crossing`：面片穿越球面，单独保留，不按重心武断分给一侧；
3. `outside`：整个面片在球外。

三组互斥且完备，全部三角形都参与总体积分。尤其是三个顶点均在球外但三角形
穿过球的情况仍被正确识别。跨界面积单列，可衡量区域分辨率：粗网格的大量
crossing面不能被当成已经空间定位到精确半径。没有对面片作子三角压力插值。

每行载荷包含该右侧面及其真实镜像的贡献：
`F=-q Cp area_vector`、`M=(center-reference)×F`，镜像力按极向量变换，
镜像矩按轴向量变换。只接受beta=0、力矩参考点在y=0、合法正半域。
按原参考S/C/U/rho输出N、Nm及CD/CL/CMy。

每个区域以及数值组件ID均报告原值、候选值、带符号差、正负差、`sum(abs(delta))`、
两算法各自绝对贡献和、面积与面积加权Cp差RMS。差值的绝对和占比用于归因；
不以接近零的净CD/CM作分母。原/候选/差值的全部力矩与系数均验证区域求和闭合。

### 几何非光滑的竞争假设

PR29仅按真实TE/contact切边分扇，不等于按所有实体几何折角分侧。
`pressure_recovery_ab.cut_vertex_gradient` 使用初始fan的面积加权平均法向作二维
拟合平面，BFS扩展只检查秩。因此满秩并不约束曲率/折角截断误差。

本程序**不修改任何cut或邻域**，只报告相邻半模面法向夹角，以及各节点patch
支持面相对初始fan面积平均法向的最大角度，并映射到接受该节点值的面元。
虚拟镜像面ID按PR29的右/左排序解析。该角度不是最大两两角度、不是物理误差，
也不等于“这个角度以上应当切开”。边角指标只统计实际半模边，不补虚拟根部边。

在同一区域看这些几何量与载荷差异，是为了区分“物理角点行为”“跨非光滑面
使用单一切平面”“势/环量/尾迹离散误差”。任何相关性仍需单变量试验确认。

参考（方法背景，不是本求解器的精度证据）：
- NASA TM-80104 描述了面元坡度不连续导致的数值速度奇性及连续速度跳跃思路，
  因而尖峰不能未经分离就认定为真实流动奇性：
  https://ntrs.nasa.gov/citations/19790016785
- FLOWPanel 的面心到节点、再到面梯度恢复说明：
  https://flow.byu.edu/FLOWPanel.jl/v1.2/geometry/panel-gradient/

## 本地执行

在独立本PR工作树，使用已验收NumPy环境：

```powershell
python -m pytest -q test/test_pressure_region_budget.py
python -m panel.pressure_region_budget --recovery-run <原396面PR29输出目录> --out runs/region_396_v1 --feature-point <x_tip_TE> <y_tip_TE> <z_tip_TE>
```

`feature-point`三值须先由保存几何核对，不能把报告中近似的尖峰坐标当CAD端点。
对相同翼身的396/1205/1966三档使用完全相同坐标、Cref和半径序列。无需重复PR29的
LU或任何CAD命令。输出 `report.json` 与 `regional_fields.npz`；记录环境与精确HEAD。

本地 Windows pytest 的目录权限问题可沿用之前已说明的等价tmp_path插件；
必须报告实际命令/退出码，不改任何数学断言、不以skip替代测试。

检查surface SHA、冻结状态hash及原Cp逐位相等，再把两套独立重积分载荷与PR29
保存报告闭合。新记录全部输入SHA和自身代码SHA；这些是本次读取时的完整性记录，
不是对旧recovered_fields的追溯签名，也不能认证文件未曾被一致修改过。

## 下一步决策表（不是预设结论）

- 固定物理半径内集中了绝大多数`sum|delta CD|`/`sum|delta CM|`，且球外差随细化下降：
  值得开展只改变局部patch几何分侧的候选；需先构造折面制造场验证，不直接裁剪压力。
- Cp最坏点在角点，但载荷差主要来自大面积球外：否定“只修角点即可”的假设，
  优先检查全表面恢复偏差、法向/几何及环量空间。
- crossing贡献主导：先增加该固定物理邻域的空间分辨率，不能将重心分类结果作归因。
- 真正讨论奇性可积性时，分别固定物理r做h细化、固定细网格观察r缩小；当前
  三档非嵌套网格不支持直接外推极限。局部最大值、未加权面RMS、面积加权误差、
  完整载荷各自报告，不能互相替代。

`physical_accuracy_accepted=false`，不把区域外载荷作为GRASS reward，不移植本研究到
生产可微后处理、不合并其他堆叠PR。PR30尾迹审计修订保持独立。
