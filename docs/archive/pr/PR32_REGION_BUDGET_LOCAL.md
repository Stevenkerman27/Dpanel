## 0. 结论（先行）

1. **输入完全可复现**：三档全部从 PR29 已保存目录重放，surface SHA-256、`frozen_state_hash`、`original_cp` 与 `frozen_state.Cp_raw_half` 逐位一致；模块对任一不匹配直接抛错（已实测篡改路径）。
2. **分区闭合精确**：4 个半径 x 3 个区域，每个半径下系数闭合误差 <= 1.11e-16、力/矩矢量分量闭合 <= 2.22e-16；全部 396/1205/1966 个半模面片都在分区内，无遗漏、无裁剪、无删面。
3. **球外主导，删角点不能消除载荷差**：r = 0.2 Cref 之外占半模面积 97.8% / 98.5% / 98.7%，却承担带符号 Delta CD 的 +97.6% / +99.9% / +65.7%，以及 sum|Delta CD| 的 92.7% / 94.4% / 73.9%。
4. **角点贡献随档非单调**：球内+穿界的带符号 Delta CD 占比 2.4% -> 0.1% -> 34.3%（1966 档候选 -23.26 的 Cp 尖峰恰好落在 r = 0.2 球内）。力矩更偏向角点：1966 档角点占 Delta CM_y 的 101.1%（球外为负、轻微抵消），但 396/1205 只有 25.0% / 56.9%。
5. **差异沿整条尖锐后缘分布，不只翼梢**：节点 patch 的 support 若同时含 +z 与 -z 法向（跨尖后缘楔形）则视为跨折角；这类面只占 13.4% / 5.9% / 4.4%，却承担 sum(area*|Delta Cp|) 的 50.3% / 43.7% / 46.3%。跨对称面（+-y）的 patch 只占 5.7% / 1.7% / 0.9%，说明对称面不是问题源。
6. **球外仍有不收敛的底噪**：球外面积加权 |Delta Cp| RMS 0.10859 / 0.07147 / 0.05715，跨折角 patch 之外（未跨折角面）的面积加权 |Delta Cp| 为 0.0993 / 0.0981 / 0.1174 —— 不随网格细化消失。
7. **决策：不做「几何折角分侧」独立候选实验。** 依据 issue #31 的判据「若球外贡献仍主导，不再只盯角点」：球外承担 66%–100% 的带符号 Delta CD，且折角效应沿全后缘分布而非翼梢局部；剩余主项属于壁面/环量/尾迹离散，而非翼梢角点。

## 4. 半径敏感性：角点（inside + crossing）贡献

| r/Cref | 角点面积占比 | 396 Delta CD 角点占比 / sum share | 1205 | 1966 |
| --- | --- | --- | --- | --- |
| 0.025 | 0.00137 | -8.5% / 0.030 | -1.4% / 0.022 | +31.2% / 0.225 |
| 0.050 | 0.00168 | -6.1% / 0.040 | -1.7% / 0.024 | +31.5% / 0.227 |
| 0.100 | 0.00653 | -4.8% / 0.044 | +0.1% / 0.050 | +33.3% / 0.249 |
| 0.200 | 0.01349 | +2.4% / 0.073 | +0.1% / 0.056 | +34.3% / 0.261 |

球外（r = 0.2 之外）三档：Delta CD = +1.18137e-02 / +1.61292e-02 / +1.18275e-02（占全局 +97.6% / +99.9% / +65.7%），
sum|Delta CD| share = 0.927 / 0.944 / 0.739，面积加权 |Delta Cp| RMS = 0.10859 / 0.07147 / 0.05715。

解读：396/1205 两档角点几乎不携带净差（2.4% 与 0.1%，甚至 396 在 r <= 0.1 时角点为负、部分抵消）；1966 档角点跳到 34.3%，
原因是候选在该档产生 -23.26 的 Cp 尖峰，尖峰所在面到角点距离 0.0（面片本身贴角点），因此被 r = 0.025 的球就装下了。
即：角点贡献的跳变是「候选尖峰的幅度」而非「物理角点的稳定贡献」。

## 5. 折角邻域审计：patch 法向跨度与差异的关联

### 5.1 定义

- 相邻面二面角：同一无向边上两三角形面法向夹角（同一顶点扇内取最大）。
- patch 法向跨度：以 patch 的 fan 面面积加权法向为参考，support 面法向与之夹角的最大值。
- 跨折角判定（本报告附加，非模块输出）：support 面法向的 z 分量同时出现 > +0.3 与 < -0.3 视为跨尖后缘楔形（记 z）；y 分量同时 > +0.3 与 < -0.3 视为跨对称面（记 y）。这只是几何指标，不证明奇性、也不证明拟合失效。

## 6. 失败边界与拒绝

- 只读：不求解、不重网格、不裁剪 Cp、不删面元、不改任何生产模块；三档全部分区相加等于完整载荷（闭合误差见第 3 节）。
- 近零净值不当 5% 分母：1205 档角点净差 2.1e-05，若用相对门槛会无意义放大；本报告一律给绝对量与全局占比。
- 不以「候选 Cp 更接近理想 Trefftz」或「候选 CD 更小」选参数；本报告不选参数。
- 篡改拒绝（本模块实测，非代码审阅）：把 `recovery_396_v1` 复制到独立目录、把 `surface_input.json` 的 density 乘 1.01 后重跑同一 `--recovery-run`，得到 `line 277, in run / ValueError: Need a successful PR29 run with a matching surface SHA`，EXIT=1，不产生输出目录。
- 覆盖拒绝（实测）：`--out runs/region_396_v1`（已存在）→ `line 268, in run / FileExistsError: Use a new output directory`，EXIT=1，旧报告未被改写。
- 模块在审计前后各校验一次输入哈希（`Input changed during audit`），并校验 `frozen_state_hash` 与 `Cp_raw_half` 逐位相等 —— 三档均通过（见第 1 节）。
- 与 #28（尾迹两侧总流残差）独立：本报告不改尾迹、不评估尾迹；与 #29 结论一致：候选不是控制组的相容细化。

## 7. 决策与下一步

1. **不进入「几何折角分侧」独立候选实验**。判据来自 issue #31：球外仍主导（66%-100% 的带符号 Delta CD；92.7%/94.4%/73.9% 的绝对差）。且跨折角面沿全后缘分布，做翼梢局部分侧无法覆盖主体。
2. **也不把球外残余当作新物理解**：球外面积加权 |Delta Cp| 0.109/0.071/0.057 是两套自洽算子的差，不是任一算子的误差估计。
3. **下一步应针对壁面/环量/尾迹离散**，候选方向（都需要同一冻结势场、只读、绝对量口径）：
   - 后缘附近的面元压力求积：TE 楔形两侧 Cp 的积分是否应按面法向再加权（当前是逐面 -Cp*n*A）。
   - Gamma 站位分辨率：22 个 gamma 自由度对 396-4371 面是否足够（尾迹近段的 dGamma/dy 重建）。
   - 尾迹近段切向性（#28 已给独立口径：近段 Delta Cp RMS 0.0098-0.0101 远高于远段 2e-05）。
4. **保留基线**：`physical_accuracy_accepted = false`；近场 CD/CM 不进 GRASS 训练；不改生产压力/核/尾迹/默认模式。
