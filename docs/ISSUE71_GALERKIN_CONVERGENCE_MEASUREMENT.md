# Issue #71 — 独立实测：P1 Galerkin 壁面算子让 CL / 点速度 / 近场 CD 同时收敛

状态：研究记录，`physical_accuracy_accepted=false`。代码随 PR #75（squash `58bb120`）进 master，算子保持 opt-in，生产默认仍是配点。

## 0. 这份文档解决什么

`docs/ISSUE71_CHORDWISE_DIVERGENCE.md` 记录：P1 配点链的 CL 随弦向加密发散（c=4..32：+0.457 → −0.819），并把病因定位到「带尖边表面的基础 P1 配点」。`docs/ISSUE71_EDGE_EXPONENT_MEASUREMENT.md` 记录了前缘 √ 模与后缘「一格宽常数跳变」的现场证据，但那时还没有替代离散。

PR #75 给出了弱（Galerkin）形式的壁面算子。本文用同一冻结几何、同一 Γ 空间、同一 Kutta 采样对做 A/B，回答一个可证伪的问题：**换成弱形式后，那些不收敛的量会不会收敛？**

答案：会。CL、固定物理点的总速度、近场 CD_p、俯仰力矩全部收敛；配点同一列全部发散。

## 1. 门禁（PR #75 文档 §4 要求的四项 + 两个恒等式）

| 检查 | 方法 | 结果 |
| --- | --- | --- |
| 质量矩阵 | 任意斜三角，独立 order-8 Duffy 求积 vs `area/12*[[2,1,1],[1,2,1],[1,1,2]]` | rel **1.30e-15** |
| 闭曲面常值恒等式 | `A_G @ 1 = -M @ 1`，icosphere 80 / 320 面 | **2.743e-16 / 2.414e-16** |
| 球面制造解 | 精确 `mu = 1.5 U x`，L2(M) 相对误差，80/320/1280 面 | 3.535e-3 / 1.100e-3 / 2.916e-4，观测阶 **1.68 / 1.93** |
| 制造解交叉验证 | 同一 Galerkin 解的配点残差 vs 精确解自身的配点残差（1280 面） | 4.266e-4 vs 4.297e-4 |
| 求积阶敏感性 | c=8，order 2 / 3 / 5 | CL 0.451921 / 0.450195 / 0.449524；CM 差 1e-4；CD_p 1.317e-2 / 1.465e-2 / 1.492e-2 |
| 边缘速度幅值 | 闭合体无切口/无尾迹，独立 lstsq，同 U | max\|V\| 2.441→1.408 (c=8, α=0)、2.230→2.011 (c=8, α=5)、2.213→1.830 (c=12, α=0)、2.584→2.304 (c=12, α=5) |

解释：

- 常值恒等式说明自面迹的 `-1/2 M_T`（P1 质量）与其余面的 PV 合成后严格等于 `-1 M`，即 `_doublet_matrix` 的内迹约定与弱积分一致，不是靠调参凑出的。
- 球面制造解的配点残差降到与精确解自身的残差同量级，说明弱解在配点范数下也已经饱和，没有留下可榨取的精度。
- 求积阶：CL 在 order 3 时已与 order 5 差 0.15%，**CD_p 需要 ≥5 阶**（order 2→5 差 13%）。共享边/近边积分是后续要做的（PR #75 文档 §4 第 1 条）。
- 边缘 max|V| 只压低 10–42%，**λ=1/2 模没有被消掉**：边缘富化仍是独立后续项，不能声称「Galerkin 解决了尖边奇性」。

## 4. 不能由本文声明的

1. **物理精度**。c=24 的 CL 0.4624 仍比 Prandtl 斜率 4.19 /rad 的 5° 估值（≈0.37–0.40）高 15% 以上；本算例有 camber=0.02 与有限翼尖，没有可比的实验/VSPAERO 参照。收敛 ≠ 正确。
2. **边缘奇性已解决**。max|V| 只降 10–42%，λ=1/2 模仍在；`docs/ISSUE71_EDGE_EXPONENT_MEASUREMENT.md` 的判据（跳变宽度随 h 收缩、固定距离点值收敛）还没在 Galerkin 解上重测。
3. **真实 CAD 可用**。A/B 只用 `make_wing` 生成几何；`cases/half_cad_wingbody_v1/surface.json` 不在仓库里，CAD 上的 Galerkin 装配（含切口、多组、尾迹耦合）尚未跑。
4. **成本可接受**。c=16+24 两个网格的 A/B 用了 247 s；装配是 O(N²·order²) 的 python 循环，比配点贵约两个量级。要进生产必须先向量化/分块。
5. **与 P0 半模的关系**。P0（`panel/half_native.py`，Neumann 型涡/源系统，Kutta 是 Γ 的代数条件）不受本问题影响，仍按 ≥1205 壁面、CL 收敛 5% 的口径使用。
