## 7. 结论

1. **采样项不是误差源，恢复项是。** 三档三势下 CD 差的 recovery 项 2.6e-4 至 1.18e-2，sampling 项只有 1e-16 至 5.3e-5（差分势恰可精确积分，故 sampling 为舍入级）；二次势上两者相差约 170 倍。3x3 与 4x4 Duffy Gauss 一致到 1e-17，说明面心采样项确实小，不是积分器假象。
2. **生产面心仿射 QR 在真实曲面上连精确仿射势都不能复原。** linear_x / linear_z 的 Cp rms 是 2.8e-3 至 1.2e-2，即场幅值 0.1 U 的 3% 至 12%。机制是模板邻面质心不在切平面内，切平面线性模型无法表示环境仿射场的法向分量（三档最大模板法向跨度 164.5 至 165.9 度，说明模板确实跨过折面）。这不是实现 bug：同一势、同一几何下 exact-node P1 参考复原到 1e-16。
3. **PR29 的 cut-aware 节点候选在精确输入上更差，不是更好。** 同一势下它的 Cp rms 是 1.3e-2 至 2.8e-2（生产的 2 至 4 倍），linear_x 在 396 上的 dCD 达 +9.220e-3，比整个真实 CD_p（6.17e-3）还大；1966 的 linear_z 单面 |dCp| 达 0.9216。切边感知的 patch 解决了秩与跨切边连续性问题，但在折面模板上放大了切平面投影误差。
4. **最坏面不在翼尖后缘，而在对称面根部与翼身交界。** 396 的最坏面在 (1.413, 0.020, -0.054)，1205 与 1966 多次落在 (0.958 至 0.970, 0.240 附近, 0.008)，都是 y 接近 0 的根部或机身翼身交界，模板法向跨度 39 至 145 度。这修正了 PR29 报告里“最坏点都在翼尖后缘角”的印象：在已知精确势下，曲率最大的根部/交界模板才是误差源。
5. **近场 CD 仍是跨组件的相消残差。** 396 的 quadratic_x2_z2：生产算子在 component 20 上 +5.851e-4、component 30 上 -4.805e-3，两项之和等于全表面 -4.220e-3；换成 PR29 候选则符号翻成 -4.463e-3 / -1.322e-3。制造势的误差量级与真实 CD_p 同阶，且以分量间相消的形式出现。

### 建议（按 PR 要求二选一）

- **不建议采用 PR29 的 cut-aware 节点候选作为生产恢复算子**：在完全已知的输入上它比现有算子更差，且在真实场上的 CD 偏移（+163% 至 +196%）方向一致。
- 若要修模板，目标应是**切平面拟合本身**（在三维里拟合并在法向分量上做约束，或直接用表面上的连续 P1 节点势装配），而不是继续加 cut-aware patch。注意 exact-node P1 只是表示参考，对二次势仍有 2.1e-3 至 1.2e-2 的 Cp rms（P1 表示误差，O(h^2)），所以它能去掉拟合误差但不能去掉表示误差。
- 本轮全部数据来自人工已知势，不满足真实翼身边界条件，不是新气动预测，也不含 CAD 真曲面误差。
