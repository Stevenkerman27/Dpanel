# 网格收敛研究：半模 NACA4412 翼身（5° 迎角）

日期 2026-10-26。目标来自用户要求：之后的算例必须用足够多的面元，气动系数至少收敛到 5% 以内。

结论先行：

| 系数 | 5% 收敛判据 | 判定 |
| --- | --- | --- |
| $C_L$（压力积分） | 1205 面板起相邻档 ≤2.4%，1205→4371 全程 +4.5% | **通过** |
| $C_L$（Kutta–Joukowski 环量） | 1205 面板起相邻档 ≤2.1% | **通过** |
| $C_D$（Trefftz 面诱导阻力） | 805 面板起相邻档 ≤4.5%，2921→4371 仅 +4.55% | **通过** |
| $C_D$（近场压力积分） | 396→4371 单调上涨 +175%，只到诱导阻力的 27%→59% | **不通过（方案缺陷，非网格不足）** |
| $C_{M,y}$ | 在 −0.0168…−0.0223 之间摆动，带宽 ±9% | **不通过** |

因此「多上面元」能解决升力与远场阻力，**解决不了近场压力积分给出的阻力与俯仰力矩**：这两个量是大幅度相消后的残差，需要用远场（Trefftz）公式或更好的压力重构，而不是继续加密网格。

## 3. 近场 $C_D$ 为什么不肯收敛

`runs/conv_diag.py` 逐面分解（`runs/conv_diag/panel_drag_decomposition.json`）：

| 壁面 | $|C_p|>2$ 面积占比 | 其阻力份额 | 细条阻力份额 | top-10 面片占绝对阻力和 |
| --- | --- | --- | --- | --- |
| 396 | 0.116% | 0.0% | 0.4% | 30.8% |
| 805 | 0.179% | 0.0% | 0.1% | 18.5% |
| 1205 | 0.120% | 0.0% | 0.0% | 12.5% |
| 1966 | 0.081% | 0.0% | 0.0% | 8.9% |
| 2921 | 0.059% | 0.0% | 0.0% | 6.4% |
| 4371 | 0.039% | 0.0% | 0.0% | 4.7% |

即：**没有奇异面元或细条在主导阻力**（它们的份额 ≈0），但净阻力只是绝对阻力和的 5%（4371 面板时 top-10 就占 4.7%）。这是典型的病态相消：净阻力 = 大量正负贡献相减的残差，任何面元级的 $C_p$ 误差（未加权切平面重构，见 `docs/PR10_PRESSURE_RECONSTRUCTION.md`）都会被放大 20 倍。所以加密网格只会让相消更彻底，不会让相消的残差收敛。

尾迹站位加密也没用（固定 size 0.13）：8/16/32 条尾迹条带 → 近场 $C_D$ 0.009252 / 0.010063 / 0.008245，无单调趋势。

## 4. Trefftz 面诱导阻力（新的验收指标）

`runs/trefftz_drag.py` 用条带常斜率 $d\Gamma/dy$ 的精确主值积分求下洗：

```python
def trefftz_cd(stations, gamma, span, chord, U=1.0, rho=1.0):
    a, b = stations[:-1], stations[1:]
    dgdy = np.diff(gamma) / np.diff(stations)      # 条带常斜率
    # 条带内: PV int dy/(y0-y) = log|(y0-a)/(b-y0)|; 条带外: log|(y0-a)/(y0-b)|
    w = -sum(s_all * logt) / (4*pi)                # 半无限尾涡系下洗
    D = -rho * sum(g_mid * w * dy)                 # 整机镜像后求和
    return D / (0.5*rho*U*U*span*chord)
```

- 镜像半翼的条带斜率取反（保持 $\Gamma$ 偶对称）。
- 校验：椭圆环量 $\gamma = g_0\sqrt{1-(2y/b)^2}$、$g_0 = 2C_LUc/\pi$、$b=4, c=1, C_L=0.6$，理论 $C_D = C_L^2/(\pi AR) = 0.02864789$：

| 站位数 | 数值 $C_D$ | 比值 |
| --- | --- | --- |
| 51 | 0.02814875 | 0.9826 |
| 101 | 0.02837890 | 0.9906 |
| 201 | 0.02850249 | 0.9949 |
| 401 | 0.02856930 | 0.9973 |

  随站位数一阶收敛到解析值，证明公式与系数正确。早期版本用点涡 $1/(4\pi)$ 求和得到恒定 0.6168 的比值，是离散求积错误（漏掉条带内的对数奇异），已废弃。
- 应用到真实半模：$C_{D,T}$ 在 805 面板起相邻档 ≤4.5%，2921→4371 仅 +4.55%，与 $C_L$ 同步收敛；近场 $C_D$ 只有它的 27%→59%，即近场压力积分系统性低估诱导阻力。

## 5. 采取的默认策略

1. 半模算例默认 `--size <= 0.13`（≥1205 壁面）；对外发布/对比算例用 1966–2921 壁面。
2. 收敛声明只对 $C_L$（压力与环量两条路径互校）与 $C_{D,T}$ 发布；近场 $C_D$、$C_{M,y}$ 一律标注「未收敛」，并附 $C_D/C_{D,T}$ 比值。
3. 上游 PR 验收脚本里的 396/805 面板算例保留（契约指定规模），但结论必须写明「$C_L$ 低 12%」。
`physical_accuracy_accepted=false` 不变：以上全部是离散收敛性，不与实验/CFD 比对。
