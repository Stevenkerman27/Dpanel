# 网格收敛研究：半模 NACA4412 翼身（5° 迎角）

日期 2026-10-26。目标来自用户要求：之后的算例必须用足够多的面元，气动系数至少收敛到 5% 以内。

2026-10-26复核：下表仅描述本序列相邻档变化，不认证渐近网格无关。多数壁面加密仍固定26站位/22个Gamma未知量；壁面、Gamma、尾迹方向/长度并未独立收敛。原始数字保留，物理精度仍未接受。尾迹研究见 [WAKE_ACCURACY.md](WAKE_ACCURACY.md)。

| 系数 | 5% 收敛判据 | 判定 |
| --- | --- | --- |
| $C_L$（压力积分） | 1205 面板起相邻档最大2.68%，1205→4371 全程 +4.5% | 本序列变化小于5%，未证明渐近收敛 |
| $C_L$（Kutta–Joukowski 环量） | 1205 面板起相邻档最大2.77% | 同上 |
| $C_D$（理想Gamma-only Trefftz量） | 805 面板起相邻档最大4.55% | 该理想模型的序列诊断，非有限尾迹解的远场认证 |
| $C_D$（近场压力积分） | 396→4371 上涨约175% | **未收敛，尚不能独立归因** |
| $C_{M,y}$ | 在 −0.0168…−0.0223 之间摆动，带宽 ±9% | **不通过** |

本序列显示升力变化比近场阻力和力矩小，但没有证明进一步加密无效。大幅相消会放大压力误差；理想Trefftz量基于另一个尾迹模型，不能替换为同一有限尾迹场的精度证据。需通过同场重构对照、尾迹物理残差及独立细化继续区分误差。

这些分解未显示少数高Cp/细条面元占主导。正负压力投影的大幅相消会放大局部误差，但不能由此推断加密必然无效，或把全部偏差归因于压力重构；需要保留投影定义与逐面证据。

固定size0.13时，8/16/32条带对应近场CD为0.009252/0.010063/0.008245，无单调趋势；这些CAD重网格同时改变了壁面面片，尚不是严格固定壁面的Gamma空间对照。

## 4. 理想Gamma-only Trefftz诊断

`runs/trefftz_drag.py` 用条带常斜率 $d\Gamma/dy$ 的精确主值积分求下洗：

```python
def trefftz_cd(stations, gamma, span, chord, U=1.0, rho=1.0):
    a, b = stations[:-1], stations[1:]
    dgdy = np.diff(gamma) / np.diff(stations)      # 条带常斜率
    # 条带内: PV int dy/(y0-y) = log|(y0-a)/(b-y0)|; 条带外: log|(y0-a)/(y0-b)|
    w = -sum(s_all * logt) / (4*pi)                # 半无限尾涡系下洗
    D = -rho * sum(g_mid * w * dy)                 # 整机镜像后求和
    return D / (0.5*rho*U*U*span*chord)
```

- 镜像半翼的条带斜率取反（保持 $\Gamma$ 偶对称）。
- 校验：椭圆环量 $\gamma = g_0\sqrt{1-(2y/b)^2}$、$g_0 = 2C_LUc/\pi$、$b=4, c=1, C_L=0.6$，理论 $C_D = C_L^2/(\pi AR) = 0.02864789$：

| 站位数 | 数值 $C_D$ | 比值 |
| --- | --- | --- |
| 51 | 0.02814875 | 0.9826 |
| 101 | 0.02837890 | 0.9906 |
| 201 | 0.02850249 | 0.9949 |
| 401 | 0.02856930 | 0.9973 |

  随站位数一阶收敛到解析值，证明公式与系数正确。早期版本用点涡 $1/(4\pi)$ 求和得到恒定 0.6168 的比值，是离散求积错误（漏掉条带内的对数奇异），已废弃。
- 应用到真实半模所得$C_{D,T}$在805面板之后相邻变化最大4.55%。但它把Gamma映射到理想平直远尾迹，并不使用已解有限尾迹的全部速度/势场；与近场CD的比值只作模型差异诊断，不能独立证明压力积分低估同一物理量。

## 5. 采取的默认策略

1. 半模算例默认 `--size <= 0.13`（≥1205 壁面）；对外发布/对比算例用 1966–2921 壁面。
2. 发布时逐项报告实际网格变化、Gamma空间和尾迹模型，不声明渐近网格无关。近场CD和CM保持未收敛；理想Trefftz量单列。
3. 396/805面板小例保留作实现检查，并注明相对于本序列最细网格的升力变化，不称为相对于真值的误差。
`physical_accuracy_accepted=false` 不变：以上全部是离散收敛性，不与实验/CFD 比对。
