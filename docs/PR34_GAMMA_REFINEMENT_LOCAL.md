两件事必须同时说：

1. **局部 Gamma 远未收敛**：4x 解与「把 1x 解按延拓算子提升」相差最大 0.058（峰值的 17.8%）/ 0.075（21.0%），RMS 0.0084 / 0.0090；dGamma/dy 的符号变化从 4/6 增到 25/27，说明细化确实在解析出更细的展向结构（包含小幅振荡）。
2. **但积分载荷几乎不动**：CD +1.9%/+2.3%、CL +0.3%/+0.4%、CM -1.9%/-4.0%。这与 PR 正文的代数解释一致：弱 Kutta 为 M Gamma = K mu，Gamma = M^{-1}K mu 的可表达空间受 K 与壁面 mu 约束，增加 Gamma 未知数不等于增加同等独立信息。

### 6. 结论（对 issue #33 的回答）

**环量分辨率不是近场 CD 相消的主导误差源。**

- 4 倍 Gamma 细化（22 → 88 个自由 DOF、m=1 时 385/733 个积分子片到 2540/4410）只让 CD_p 变 +1.9%/+2.3%、相消因子变 -1.7%/-2.0%，**近场/理想 Trefftz 比值从 0.2483→0.2500（396）、0.3238→0.3263（1205），即 <1% 的差距被解释**。
- 对照：同一套恢复算子下，网格 396→4371 使 CD_p 从 0.006168 涨到 0.016968（+175%，PR26 审计 A），而 1→4 倍 Gamma 细化只给 +1.9%/+2.3%。两者相差约两个数量级。
- 因此「沿全后缘的 Gamma 分辨率不足」这一假设**被证伪**（在其可检验形式上）；下一步不应再投在 Gamma 展向细化上。
- 附带确认：TE 势跳跃 L2 随细化单调下降 36%/33%（0.01035→0.00658、0.01008→0.00675），说明新增 DOF 确实改善了弱 Kutta 的可表达性，只是这不体现在近场阻力上。
- 实现层面全部通过：1x 位级回归（<=1e-13）、三条嵌套恒等式（<=1.8e-15）、面积/一阶矩/TE 长度守恒（<=1.5e-15）、质量矩阵正定（条件数 16.9–21.5）、真残差 <=1.4e-15。**旧空间能被新空间精确表示**，所以本轮的差异是物理空间效应，不是实现错误。
