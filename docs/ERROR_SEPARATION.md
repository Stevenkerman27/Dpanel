# 误差分离实验：几何 / 离散 / 势重构 / 尾缘条件

日期 2026-10-25。执行 `PAUSE_HANDOFF.md` 恢复起点 ③：在明确支持域内分离四类误差来源，不做裁剪、不做正则化、不移动配置点。

## 1. 方法与可复现入口

脚本 `panel/verify_error_budget.py`（本轮新增，已参数化 `--out/--radius/--aft/--sizes/--audit-python`）：

- 几何：`lifting3d/results/cad_inputs_v1/naca0012_wing` 的翼 + Gmsh OCC 生成的椭球机身（半轴 2 / 0.35 / 0.35），平移机身使尾尖落在 x = 0.9999（离缝 1e-4）、1.0（精确相切）、1.0001（侵入 1e-4）。
- 网格：`--radius 8`（radius 5 的保守包围盒会拒绝近相切工况，见 `runs/panel_cad_limits_r8`），h = 0.3 / 0.2 / 0.15；接触工况跑全部三档，另两个 aft 只跑 h = 0.3。
- 每算例：`cad.py` → `solve.py` → `panel/audit.py`（独立 numba 核，不调用 JAX 求解器）。
- 产物：`runs/panel_error_budget_v2/`（`*/record.json`、`*/solve/fields.npz`、`*/solve/independent_audit.json`、`summary.json`）。`runs/panel_error_budget_v1/` 是同代码的重复实验，用于检查可重复性。

两条互相独立的升力通道，用来交叉校验：

- **Cp 通道**：CL = −Σ Cp_i A_i n_z,i / S_ref（生产路径，逐点 Cp 由切平面仿射最小二乘重构）
- **环量通道**：CL = 2 Σ Γ_i Δy_i / S_ref（Kutta–Joukowski，只依赖环量未知量与站位）

两者一致则逐点压力重构可信；差值就是"势重构 + 逐点求值"这条链路的误差。

## 3. 四类误差预算（接触工况 aft=1.0001 为基准）

| 误差源 | 度量 | h=0.30 | h=0.20 | h=0.15 | 结论 |
|---|---|---|---|---|---|
| 离散 | Cp 通道 CL 变化 | — | +0.051818（+20.6%） | +0.016129（+5.3%） | 未收敛，从下方逼近；比值 3.21 |
| 离散 | 环量通道 CL 变化 | — | +0.007032（+2.1%） | +0.002391（+0.7%） | 已基本收敛 |
| 势重构 | CL(Cp) − CL(环量) | −23.4% | −9.9% | −5.8% | 粗网格上最大单项误差，单调收敛 |
| 尾缘条件 | TE ΔCp 折算的 CL 误差 | 2.00% | 1.08% | 0.76% | 次之，随 h 下降 |
| 几何变化 | h=0.30 上三个 aft 的 CL 展布 | 0.008449（3.40%，Cp） | — | — | 与尾缘条件同量级 |
| 几何变化 | 同上，环量通道 | 0.007662（2.35%） | — | — | 同结论 |
| 线性代数 | 相对残差 | 7.7e-16 | — | — | 不是误差源 |

排除了一个假的"误差源"：`panel/audit.py` 在面元重心直接求速度得到的逐点 Cp 在粗网格上有尖峰（h=0.3 时 field Cp_min = −15.75，而 `Cp_raw` 为 −1.0092；h=0.15 时 −3.03 vs −2.38）。因此 `reconstructed_vs_field_cp_rms`（≈0.20）不能当作重构误差，它主要度量独立求值器自身的奇异性误差。可用的独立量是壁面法向 RMS：0.0391 → 0.0331 → 0.0202 U，与网格同向收敛。

## 4. 结论

1. **离散误差是第一大项**：Cp 通道 CL 从 0.2517 涨到 0.3196（+27%），h=0.15 仍未到位；环量通道几乎不动（0.3299 → 0.3393，+2.9%）。压力积分对网格远比环量积分敏感。
2. **势重构（逐点 Cp）是第二大项**，不是小修正：粗网格上 Cp 通道比环量通道低 23.4%，最细网格仍低 5.8%。方向是系统性低估升力，说明切平面仿射最小二乘在近前缘/近接触区的速度重构偏小。
3. **尾缘条件不是主要误差源**：TE ΔCp 折算 CL 误差 2.00% → 0.76%，弱势跳跃闭合没有引入虚假升力。
4. **几何（三种相切状态）只值 2–3%**：0.9999 / 1.0 / 1.0001 三档在 h=0.3 上 CL 展布 0.0084。此前"双机身粗/细 CL 差 18.6%"应主要归于离散与重构，而不是接触几何不可信。
5. 因此 `physical_accuracy_accepted = false` 的正确解读是：**逐点压力重构 + 网格不足**，而不是环量/载荷关系错了。用 CL 做验收应以环量通道为基准并声明网格等级。

## 5. 可重复性观察

v1 与 v2 用同一脚本、同一参数重跑，Gmsh 重新生成 fixture 后网格并不逐位相同：接触工况 h=0.3 的面元数 678（v1）vs 682（v2），CL 0.250098 vs 0.250818（差 0.3%）。结论不受影响，但网格生成不是位可重复的，跨轮比较必须核对面元数与 `surface.json` 的 SHA-256，不能假定同参数即同网格。

## 6. 支持域与未覆盖

- 支持域：显式共形平面切、流向常值跳跃、固定拓扑；机身与翼的接触由切平面显式生成真实相交线，没有封口、没有裁剪、没有涡核、没有 SVD 截断、没有移动配置点。
- 未覆盖：h<0.15；更高阶/受约束的 Cp 重构；非平面尾迹；接触拓扑随参数变化（不可微）；实验数据对比（本仓库没有可信风洞基准）。
