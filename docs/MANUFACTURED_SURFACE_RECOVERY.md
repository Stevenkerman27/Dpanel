# 真实冻结模板的已知势验证（Issue #35）

## 结论与范围

本工具把“输入势不准确”和“从面心势恢复表面速度不准确”分开，给下一步压力恢复或连续P1壁面势设计提供依据。它不改生产解、没有新的气动求解器、不会把PR29候选设为默认。

依据PR34本地 `f9f520a`：在396/1205两个固定壁面及水平尾迹模型上，22→88自由Gamma使CD改变+1.89%/+2.35%，但局部Gamma差和斜率波动尚未收敛。因此暂不追加Gamma档位，不能把这一有限实验写成一般性排除了环量误差。PR30既有审阅修订独立继续；缺少可信后缘速度前，不做压力Kutta生产替换。

本模块只用NumPy和既有 `panel/pressure_recovery_ab.py`。输入为原PR29目录的五个文件：`surface_input.json`、`frozen_state.npz`、`recovered_fields.npz`、`patches.json`、`report.json`。读取前后核对SHA、冻结状态哈希、原Cp逐位关系；先用原mu和冻结邻接复现原Cp。既有记录不能被覆盖。

## 1. 明确的制造势，不是假冒物理解

令 `X=(x-origin)/Cref`，规定 `phi=a*U*Cref*f(X)`，默认a=0.1，势原点(0,0,0)。所有网格使用同一原点和幅值，不随误差调参。六个模式：常数、X、Z、XZ、X²−Z²、Y²−Z²。它们关于y=0偶对称，并是环境空间中的调和多项式。

参考梯度是 `g_exact=(I-n*n^T) grad(phi)`，n为每个**原平面三角形**的法向。这是已知标量限制到当前面片后的精确导数，不是CAD曲面的真值，也不是满足机体无穿透/Kutta的外流解。

对照表面速度定义为 `v_exact=(I-n*n^T) Uinf+g_exact`，Cp=1−|v|²/U²。这里的切向投影是制造标量测试的明确定义，不能用于删除实际解析流场的法向误差，更不证明壁面边界条件通过。制造载荷不是设计载荷。

## 2. 三个被比较对象

- `affine_qr`：PR29控制组，沿用**原冻结**面心邻接，在已知面心势上运算；不扩大/挑选邻域。
- `cut_vertex_candidate`：PR29被否决升级的候选，仅作为研究对照。所有真实TE/contact切边保留，重新生成的几何patch签名必须与已保存patch完全相同。不采用它作默认。
- `exact_vertex_p1_reference`：直接把已知势的**精确节点值**送入三角P1梯度。它隔离“面心到节点转换”与“P1表示”差异，不是求解出来的P1结果，也不支持宣称P1求解器已实现。

环境空间仿射函数在曲折模板上不必被面心切平面拟合精确恢复：邻居位移含法向分量，而设计矩阵只拟合两个切向分量。程序测量这一偏差，不把它预设为实现错误。平面仿射、真正分侧跳跃和精确节点P1的仿射恢复另有严格测试。

## 3. 两层可闭合误差分解

第一层在同一面心比较速度恢复。令e=v_rec−v_exact，记录

`Cp_rec−Cp_exact = −2*v_exact·e/U² − |e|²/U²`。

保留线性交叉项与平方项，逐面自检恒等式；梯度误差以U归一化。即使参考梯度为零，也不使用不稳定的相对误差分母。

第二层比较载荷：

`L_rec_center − L_exact_integrated`
`= (L_rec_center − L_exact_center) + (L_exact_center − L_exact_integrated)`。

第一项是恢复贡献，第二项是**对已知面内连续场**使用面心采样的偏差。所有项均使用相同几何、法向、参考量与-qCp*n*A；不是给法向再次加权。对于原来已经定义为逐片常量的Cp，增加积分点没有收益，本工具不伪造这种收益。

采用正权3×3 Duffy张量Gauss求积，另以4×4自检。二次势的梯度一次、Cp二次、力矩三次。Duffy变换后u次数至多d+1、v次数至多d，3点一维Gauss对5次多项式精确，因此在本测试空间的平面片上精确至舍入误差。单测同时用独立解析单项式积分检查到总次数4，且有显式二次Cp力/力矩公式，非仅两种数值求积互比。

镜像力按极向量、力矩按轴向量恢复。报告完整表面、真实TE相邻面、其余面、数值组件ID；每个面和异常均保留。TE相邻组与其余组构成完整分区，组件也完整分区，不将被排除区域后的值当新物理解。

## 4. 产物

`report.json`：输入/源码哈希、原状态控制误差、每个制造势的每种算子的面积加权梯度/Cp误差、三个制造载荷系数和恢复/采样贡献、逐面绝对差总和、求积和分解闭合。

`manufactured_fields.npz`：每面参考梯度、面心Cp、积分载荷、各算子梯度/Cp/线性与平方误差、力矩和系数贡献；原邻接法向跨度、TE标记、组件和面心。面积同时明确输出半模和镜像全模，禁止互相误标。

若候选patch失败或任何验证失败，返回非零退出并保留失败report；不隐式忽略该算子。原输入匹配失败在创建输出目录前拒绝。全流程无JAX/Torch/Numba/SciPy/Gmsh导入、无求解/重网格，默认最多2200右半壁面。

## 6. 下一步决策

精确输入下恢复偏差大，优先检查整个真实模板的曲率/折角/分侧误差；若精确节点P1明显更可靠，仅支持评估求解级P1最小原型，不证明它解出来一定更准。

若精确输入下原恢复已可靠，而实际数值势仍敏感，转向壁面解空间/边界闭合，不再盲目改拟合权重。若已知压力的面心采样贡献主导，未来变阶速度/压力表示须配套合适求积；仍不能把原P0常压场“多采点”当修复。

这些误差仅属于制造场与当前平面几何。CAD几何误差、真实翼身势误差、非线性压力Kutta、自由尾迹及设计梯度尚不在本工具内。完整物理验收依赖独立参考、真实局部场/载荷收敛及可信尾迹/后缘速度。
