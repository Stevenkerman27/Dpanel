# airfoil2d

二维翼型求解器（面元 + P2），含映射/对偶不变性研究与「强制修复」实验。

| 分组 | 文件 |
| --- | --- |
| 求解 | `solve.py`、`p2.py`、`build_mesh.py` |
| 研究 | `run_study.py`、`run_invariance.py`、`run_extra.py`、`run_extra_repair.py`、`plot_results.py` |
| 测试 | `test_mapping.py`、`test_p2.py` |
| 协议/结果 | `PROTOCOL.md`、`RESULTS.md`、`EXTRA_*.md`、`REPAIR_PROTOCOL.md` |
| 旧版 | `archive/`（早期实现，仅作溯源） |

产物：`airfoil2d/results/`、`airfoil2d/meshes/`。
