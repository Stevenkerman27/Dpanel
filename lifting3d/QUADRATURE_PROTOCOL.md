# 厚翼身固定网格积分对照

本协议在新的四阶积分求解之前登记。复用
`results/wingbody_matrix_v1/t024_r035_a090/mesh/mesh.npz`，
保持 M0、alpha5、weak Kutta 和 NCPU=8，只将体/面/后缘积分阶数由3改成4。
参考三阶原始解为同目录 `m0_a5`；不重网格、不改变压力或边界条件。

逐项记录方程收敛、压力与Gamma升力、分部件载荷、原始壁面法向RMS、
连接区RMS、尾迹压力和通量跳跃。数值一致性门限预设为
`|CL4-CL3| < .002`；组件求和误差 `<1e-10`；全部原始Cp有限。
方程/Kutta最终残差要求 `<1e-9`。这些不是绝对精度验收。

若积分阶数改变导致差异超过门限，原样保留失败，不能通过更换参考解、
降低积分阶数或修改门限消除失败。若通过，也不证明网格收敛或自由尾迹成立。

v1使用的历史三阶解与当前四阶解的求解器哈希不同，不能作为严格受控对照。
v2在同一固定原网格上用当前求解器重算三阶解，复用已保存、源码哈希完全相同的
四阶解；强制验证二者求解器与网格哈希一致。v1原始摘要保留。
