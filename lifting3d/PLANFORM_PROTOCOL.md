# 梯形与后掠平面形扩展

保持根弦为1，半展长为b/2，厚度比在局部弦长上定义：

```
c(y) = 1 + (taper - 1) * 2*abs(y)/b
x_LE(y) = abs(y)*tan(sweep) + (1-c(y))/4
x_TE(y) = x_LE(y) + c(y)
Sref = b*(1+taper)/2
```

sweep是四分之一弦线后掠角。三个截面（负翼尖、翼根、正翼尖）通过OCC直纹实体放样，不扭转、不改变NACA原始尖边。默认矩形仍走原挤出分支，保留历史几何。

每个CAD尾迹条带的起点取实际 `x_TE(y)`，必须使用包含y=0的偶数条带，以免面跨越根部平面形拐点。后缘节点由几何方程识别；Kutta仍为原始上下顺弦速度迹的节点或帽函数积分约束，顺弦方向为全局x。物面分区和可选固定尾迹倾角改用局部弦坐标。Gamma仍按y分段线性，翼尖为零。图式自由尾迹试验尚不支持这组变起点平面形，明确拒绝。

机身尾端必须小于整个后缘的最小x；仅检查根部后缘不够。归一化长度为根弦，面积使用实际梯形投影面积。无扭转/弯度，不推断一般CAD后缘。

首批在运行前规定：taper=.5/sweep0、taper1/sweep20、taper.5/sweep20，h=.2、曲率32、24条带、M0、alpha5度，先检查7项几何/拓扑、Sref公式、全部原始Cp有限及最终残差/Kutta<1e-9。组合平面形复用固定网格加跑0/-5度，零升力、正负攻角压力/环量反对称要求1e-9。所有壁面和尾迹原始误差完整保存；上述检查只认证实现一致性，不认证气动精度。
