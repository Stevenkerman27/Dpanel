# Prandtl 升力线独立参考结果

日期：2026-10-23；配对证据修订：2026-10-23。执行协议见 [LL_PROTOCOL.md](LL_PROTOCOL.md)，线性计算脚本为 [lifting_line.py](lifting_line.py)。原始计算保存在 `results/lifting_line_v1/`；采用正确同批三维配对来源重算的结果保存在 `results/lifting_line_v2/`。PNG 和 CSV 给出 AR=4、α=5° 环量对照。

## 结论范围

解析椭圆弦长 patch、矩形翼 N=16/32/64 展开、AR=4/8/20 和两种 `a0` 模型均按预注册设置完成。解析 patch、N32→N64 的 CL/CDi 变化门限、正负攻角对称检查均通过。

这些结果是独立的低阶 Prandtl 升力线一致性参考，不是三维全势解或精确有限厚度翼的三维真值。与已保存三维解的比较不构成 solver 验收，也没有使用三维 solver 系数来选择或校准 `a0`。升力线 `CDi` 是由 Γ 模态算出的诱导阻力；三维 `CD_pressure` 是 solver 压力积分，二者不是同一载荷定义。

## 解析椭圆弦长 patch

取 AR=4、α=5°，椭圆弦长 `c(θ)=croot sinθ`，解析解只有 A1 非零。N=16/32/64、两种 section slope 的六个 patch 均通过：

- 最大解析系数代回配点方程残差：`5.56e-17`。
- 数值系数解与解析系数的绝对差小于 `1e-12`；数值高阶模态小于 `1e-12`。
- 模态公式与独立 θ 数值积分所得 CL、CDi 的最大相对差分别为 `4.30e-16`、`4.36e-16`。

N=64 解析值：

| 薄翼 `a0=2π/rad` | 0.029088821 | 0.365540904 | 0.010633154 |

## 可追溯性与未完成范围

- NACA0012 斜率来源：`airfoil2d/results/general_v1/20_n12_02_a5_m0/result.json`，α=5°、M=0、`CL_pressure=0.5990206726228917`，故 `a0=6.864271276475894/rad`。该斜率是已保存的二维有限厚度 P2 结果驱动近似，不是普适精确值。
- 椭圆翼根弦 `4b/(πAR)`、面积、矩阵和二次阻力公式按协议直接计算；未重建几何或调用主 solver。
- 请求 NCPU=8；本机 BLAS 与 OpenMP 均实际报告 8 线程。脚本记录的 wall time 为 `0.14015 s`，不含文档整理时间。
- `lifting_line_v1/summary.json` 保留原始配对来源；`lifting_line_v2/summary.json` 记录修订脚本与协议、当前 solver 源、NACA 二维输入、同批三维结果/网格 metadata 及另列高分辨率网格 metadata 的 SHA256，并分别保存来源 mesh、solver、P2、protocol hashes。
- 尚未完成：不同翼型/展向载荷的升力线验证、截断阶数高于 64 的研究、与未来 AR=8/20 三维解对照、非线性/黏性效应及独立三维真值比较。不能从这里推出失速、黏性阻力或任意几何下的准确度。
