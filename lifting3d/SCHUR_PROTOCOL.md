# 精确Schur分块后端

预登记目标：全壁面0.5h细化使厚翼身未知量由113012增至523020，原整块LU
求解的实际工作集已超过13GB。先尝试改变线性代数求解组织，保持Galerkin、
Kutta、Gamma基、后缘拓扑、压力和全部原验收门限。

Newton增量的原方程为

```
A dpsi + B dgamma = -r_psi
C dpsi + D dgamma = -r_gamma
z = A^-1 (-r_psi)
W = A^-1 B
S = D - C W
dgamma = S^-1 (-r_gamma - C z)
dpsi = z - W dgamma
```

A是施加原势基准后的势块，Gamma自由度保留全部。A仍用SuperLU默认COLAMD，
S用普通密集线性求解；不截断奇异值，不加正则化，不删除Kutta约束。谱诊断只
对小型Schur矩阵计算，不能把A块LU主元比冒称整矩阵条件数。

每一步用原完整块方程独立回代，要求相对线性残差 `<1e-9`。退化Schur矩阵必须
明确失败并保留原系统。先通过独立SPD势块/非对称环量闭合的解析已知向量
patch，以及真实奇异环量闭合明确拒绝测试。

实际网格先复用planforms_v1/combined的固定网格，两个后端均用同一新版本源码、
M0/alpha5、weak Kutta，检查phi/Gamma/原始Cp/速度/压力力逐项绝对差 `<1e-9`。
随后在原厚翼身113012节点的固定网格重复同一比较；只有通过才能考虑用于
大自适应网格。分别报告离散系统组装、线性求解、回代残差与LU非零数；若没有
独立峰值内存测量，不把非零数直接称作峰值内存。未预设一定更快或更省内存。
