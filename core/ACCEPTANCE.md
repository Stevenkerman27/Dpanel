# 面元内核参考算例与验收门禁

本目录的参考网格独立于求解器实现，不导入 `core` 求解器，也不使用 OpenVSP 生成几何。运行 `python core/reference_cases.py` 会写入 `core/reference/` 下的 NPZ 网格与 `analytic_reference.json`。生成脚本使用 NumPy 和 `scipy.integrate.quad`。

## 解析参考与推导核验

来流取 `U_inf=(1,0,0)`、密度 `rho=1`。球体单位法向为 `n`，解析表面速度为

`V_t = 3/2 * (U_inf - (U_inf dot n) n)`.

该式满足表面法向速度为零；由不可压、无旋外流的球谐势解，球面势系数为 `3/2`。因此 `Cp = 1 - |V_t|^2/|U_inf|^2`，完整闭合球面积分的压力合力为零（d'Alembert 悖论）。

对于轴向半长为 `a_i`、半轴为 `(a,b,c)` 的椭球，采用去极化因子

`L_i = abc/2 * integral_0^inf ds / ((a_i^2+s) * sqrt(product_j(a_j^2+s)))`.

为独立核验椭球式，使用外部 confocal 坐标 `lambda`，由

`sum_i(x_i^2/(a_i^2+lambda)) = 1`

定义

`L_i(lambda) = abc/2 * integral_lambda^inf ds / ((a_i^2+s) * sqrt(product_j(a_j^2+s)))`.

扰动势与总势分别为

`psi = sum_i(U_i*x_i*L_i(lambda)/(1-L_i(0)))`,

`Phi = U_inf dot x + psi`.

在表面 `lambda=0`，总势化为 `Phi = sum_i(U_i*x_i/(1-L_i(0)))`。对外部总势按 `x` 求导，再与椭球法向 `n` 点乘，边界条件为 `n dot grad(Phi)=0`。脚本在四个非主轴表面点直接计算该导数，并与切向速度闭式比较；误差门槛为 `1e-10`，结果写入 `analytic_reference.json`。切向速度闭式为

`V_t = (I - n n^T) diag(1/(1-L_i(0))) U_inf`.

它是表面势梯度的切向分量，不是势函数在空间中简单取常梯度。该数值表面导数核验独立于球形极限自检。另一个代数自检是球形极限下积分给出 `L_i(0)=1/3`，表面势系数 `1/(1-L_i(0))=3/2`，恢复上述球体结果。三轴积分由 `scipy.integrate.quad` 计算。本轮公开检索未取得可核查的原始教材或论文内容，外部来源不足以独立核实上述完整三轴积分推导；因此本文件明确把它作为按边界条件推导、经表面法向导数数值核验和球极限自检的解析基准，而不声称由 OpenVSP 或外部求解器验证。

解析 `Cp` 一律从同一表面速度计算：`Cp=1-|V_t|^2/|U_inf|^2`。不要混用压力中心、面心速度和顶点速度；离散比较时须注明解变量的位置及其到面中心的插值方式。对闭合物体，总压力力必须使用唯一一致的来源：在面中心计算 `Cp` 后用 `F = -q_inf * sum_f(Cp_f * n_f * A_f)` 积分一次。不得再叠加压力系数积分、势流动量积分或其它重复来源。均匀参考静压对闭合面的合力应为零。

## 求解器验收门禁

以下门禁是后续内核验收要求，不代表当前数据生成脚本已经求解或通过求解器测试。

1. **源通量守恒**：闭合网格报告有向源通量总和，并按 `|U_inf| * sum_f(A_f)` 归一化；绝对归一化通量必须 `<= 1e-12`。同时报告未归一化值和离散精度。
2. **质心真实无穿透**：总速度必须检查 `r_f = V_total,f dot n_f`，并以 `|U_inf|` 归一化，质心采样的面积加权 RMS 必须 `<= 1e-6`、最大绝对残差必须 `<= 1e-5`。若未知量是扰动速度 `V_perturb`，等价残差是 `V_perturb dot n + U_inf dot n`，因为 `V_total=U_inf+V_perturb`；不能把 `(V_total-U_inf) dot n` 当作无穿透残差。报告真实物理残差，不得用线性系统残差替代。若硬质量约束造成离散相容性误差超过阈值，必须实报超限，不得调松门槛或隐藏残差。
3. **L4 面内独立采样**：除质心外，在每个 L4 三角形内使用重心坐标 `(0.6,0.2,0.2)` 的三个循环置换 `(0.6,0.2,0.2)`、`(0.2,0.6,0.2)`、`(0.2,0.2,0.6)` 独立评价边界速度；合并三组点的无穿透残差，按 `|U_inf|` 归一化后的 RMS 必须 `< 0.1`。这是低阶原型门槛，不能替代质心严格门槛。
4. **球面与椭球 Cp 加密收敛**：分别对球与 `(3,1,1)` 椭球比较 L2/L3/L4 面中心解析 `Cp`，使用面积加权 RMSE。L4 的 RMSE 必须 `< 0.08`，且相邻级误差比 `RMSE(L3)/RMSE(L2)` 与 `RMSE(L4)/RMSE(L3)` 均须 `< 0.8`。球、椭球分别过门槛；不得以后验调参改变门槛。
5. **对称网格压力合力**：球与椭球每级闭合网格按唯一压力积分来源计算 `C_F = |F|/(q_inf*S_ref)`；这些对称网格上的压力合力系数必须 `< 1e-8`。报告三分力、`q_inf`、`S_ref`、面法向方向及面心 `Cp` 来源。
6. **坐标变换不变性**：对 L3 球分别测试 scale `0.001`、`1000`，指定平移、指定旋转，以及几何和来流同时旋转的组合。将速度按向量逆变换、压力按无量纲量比较；与基准解的差异必须 `<= 1e-9`。同时报告无穿透、`Cp`、通量及压力力差异。大绝对坐标和极端尺度下报告条件数或适当稳定性诊断。
7. **网格几何有效性**：输入求解前拒绝零面积面、重复节点索引、非流形边、开口边界和朝向混乱；参考生成物应为外向一致闭合三角网格。
8. **压力积分唯一性**：全流程只使用上文定义的一个面压力积分来报力；验收记录要标注其输入 `Cp` 来源，并确认没有将重复压力或动量结果相加。
9. **固定尾迹与 Kutta 延后**：本批参考体均无尾迹，重点验证封闭体源/双元内核与边界条件。升力体的固定 wake、Kutta 条件另设阶段和独立算例；不得用未收敛解、失败解或不满足残差门槛的结果宣称通过。

每次验收应记录代码版本、网格文件、求解配置、残差定义、容差、完整误差表和力积分来源。缺少任一门禁的数据即记为未验收，而不是默认通过。
