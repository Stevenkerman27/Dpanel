# 对数径向坐标与一致表面导数：方案 v1

日期：2026-10-23，首次新求解前记录。保留原 `solve_airfoil.py` 与 lifting_v1 证据，不覆写其压力。

## 变量与离散

令 `s=log(r)`，`0<=s<=log(R)`；物理映射保持 `zeta=c+a*exp(s+i*theta), z=zeta+1/zeta`。连续方程精确变换为

`d_s(rho*Phi_s)+d_theta(rho*Phi_theta)=0`。

计算平面 `(s,theta)` 使用等距单元中心 FV。每个内部面仍共享唯一质量通量；密度取相邻单元算术平均，外边界半单元距离。物理速度平方为

`q^2=(Phi_s^2+Phi_theta^2)/[a^2*exp(2s)*abs(dz/dzeta)^2]`。

这不是人工扩散、边界投影或压力修正。使用对数坐标是为了与圆周自然径向条件相匹配，须以独立误差与收敛验证其作用；不能从这张保角网格外推一般几何保证。

总势仍为周期部分加 `k*t`，k 联立求解。二阶 Kutta 导数使用跨后缘两点；四阶 Kutta 使用跨后缘四点：

`Phi_theta(TE) ≈ 9/8*(psi[0]-psi[-1])/dt - 1/24*(psi[1]-psi[-2])/dt + k`。

四阶物面/单元中心周向导数为标准五点中心格式，明确与 Kutta 同阶。二/三/四次径向多项式均可选，其值和导数从 s 单元中心外推。主方案采用二次径向、四阶周向；不强制重构法向速度等于零，完整速度仍进入 Cp。

## 首批门禁与计算

1. 对称 M=0、5 度、exact 外边界，32x128、64x256、128x512。Cp 加权误差与局部法向最大误差须随加密下降；最细 Cp RMSE<0.002、CL 相对误差<0.002、绝对 CD<0.0005、独立壁面法向最大误差<0.01。
2. 128x512 比较周向二/四阶与径向二/三/四次，所有结果保留；不以最小单个误差挑选方法，须同时报告解析样本截断误差与数值势误差的贡献。
3. 128x512 对称 alpha=-5/0，epsilon=0.04/0.16/0.30 的厚度变化与 eta=0.04 的弯度，M=0 exact。Cp RMSE<0.005、CL 绝对误差<0.005；对称零升力与正负攻角关系<1e-8。
4. 128x512 仅加周向到 1024、仅加径向到 256，用于误差分辨率匹配诊断，不预设后验通过阈值。
5. M=0.001 exact 与 M=0 的最大 Cp 差<1e-4。M=0.1/0.2/0.3 uniform，64x256；M=0.2 另测128x512和R=10/40，报告敏感性，不声称外部可压精度认证。
6. 更新后密度质量散度 RMS<=1e-9、最大<=1e-7，Kutta<=1e-10，净质量通量/chord<1e-9。局部声速状态与非正等熵状态显式退出；M=0.6用于验证范围退出。
