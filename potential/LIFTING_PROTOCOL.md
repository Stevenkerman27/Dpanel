# 二维升力验证方案 v1

日期：2026-10-23。在本阶段首次计算前记录。目标是验证环量符号、尖后缘 Kutta、势跳跃和压力载荷；不是验证任意翼型网格、三维尾迹或跨声速激波。

## 模型与符号

使用 Joukowski 映射 `z=zeta+1/zeta`，`zeta=c+a*r*exp(i*(theta0+t))`，`c=-epsilon+i*eta`，`a=abs(1-c)`，`theta0=arg(1-c)`，`r>=1`，`0<=t<2*pi`。尖后缘在 `zeta=1,z=2`；默认 epsilon=0.08，eta=0，另检验 eta=0.04 的弯度。

`Phi=psi+k*t`，psi 周期，`Gamma_CCW=2*pi*k`。逆时针环量为正，来流 `(cos(alpha),sin(alpha))`，因此正升力对应负环量，`CL_Gamma=-2*Gamma_CCW/chord`。切割线上总势跳跃为 `2*pi*k`，共享质量通量不跳变。这里是定常二维无旋流的拓扑切割，不是三维自由尾迹模型。

保角映射后方程为 `div_zeta(rho*grad_zeta(Phi))=0`；物理速度还需除以 `abs(1-1/zeta^2)`。内部面共享同一通量；物面给定零通量。Kutta 要求尖后缘的映射平面切向导数为零，使用跨切割面的中心差分与前三径向单元的二次壁面外推构成一个线性方程，同时求解 k。不能将相邻面心压力相等直接作为解析后缘极限。

M=0 的独立解析参考：

```text
w = zeta-c
W = exp(-i*alpha)*w + a^2*exp(i*alpha)/w - i*k*log(w)
k_exact = 2*a*sin(theta0-alpha)
dW/dz = [exp(-i*alpha)-a^2*exp(i*alpha)/w^2-i*k_exact/w]/[1-1/zeta^2]
Cp_exact = 1-abs(dW/dz)^2
```

外边界分两类：exact 使用上述非环量解析势，避免有限远场与无限域解析解混比；uniform 使用物理平面均匀流势，单独报告远场敏感性。exact 边界只在 M=0 有解析精度意义。未知环量不从解析公式赋值；每例从单位密度线性求解开始，再进行密度冻结迭代。

## 预设计算

- M=0，alpha=+5 度，对称翼型 exact 边界，`32x128,64x256,128x512` 三档。
- M=0，对称翼型 alpha=-5/0 度，`128x512`；弯度 eta=0.04，alpha=0/5 度，`128x512`，均为 exact。
- M=0.001，对称翼型 alpha=5 度，`128x512`，exact，用于低马赫一致性。
- M=0/0.1/0.2/0.3，对称翼型 alpha=5 度，`64x256`，uniform；M=0.2 另用 `128x512`。
- M=0.2，uniform，R=10/20/40；径向点数随 log(R) 调整，近壁分辨率近似相同。
- M=0.6 检查当前中心椭圆格式的局部声速退出行为，不能当作跨声速物理解。
- 独立常源/常涡二维面元至少检验对称翼型 alpha=-5/0/5 和网格加密。其无限域 polygon 几何与映射 FV 网格不同，只作独立交叉证据。

## 接受判据

1. 更新后密度的物理体积散度 RMS <=1e-9，最大值 <=1e-7；Kutta 离散残差 <=1e-10。
2. 外边界净质量通量按 `Uinf*rhoinf*chord` 归一化，绝对值 <1e-9。报告切割面两侧通量严格配对的独立检查。
3. M=0、alpha=5、exact 最细档：弧长加权 Cp RMSE <0.02，环量相对误差 <0.005，压力 CL 相对解析误差 <0.005，压力 CL 与数值环量 CL 的相对差 <0.005，绝对 CD <0.002。
4. 该三档加密 Cp RMSE 相邻误差比 <0.8。其他 M=0 exact 案例的绝对 CL 误差 <0.005、Cp 加权 RMSE <0.02。
5. 对称翼型 alpha=-5/+5 的 CL 之和 <1e-8，alpha=0 的绝对 CL <1e-8。
6. M=0.001 与同网格 M=0 的最大 Cp 差 <1e-4；这不是非零 Mach 的绝对精度证明。
7. 独立壁面法向速度保留在压力计算中，报告弧长加权 RMS、最大值和加密变化。尖后缘为坐标奇点，所有表面点都参与统计，不裁掉后缘点。此阶段不预设其点态门禁，也不声称满足原三维配点 1e-6 要求。
8. 非零 Mach 的环量/压力升力差、CD、网格/远场差如实报告。不可压 Kutta-Joukowski 数值关系不是可压全势在有限远场下的独立精度认证；没有外部可压参考时不升级为模型精度通过。
