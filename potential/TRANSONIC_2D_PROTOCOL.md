# 二维流向密度偏置方法协议（设计稿）

## 定位和证据边界

本文件规定未来独立二维方法验证的步骤，不修改 `solve_airfoil.py`，也不是已实现/已认证方法。目标方程仍是无旋、等熵全势方程

```text
div_x(rho grad_x(phi)) = 0
rho = [1 - (gamma - 1) M_inf^2 (|grad_x(phi)|^2 - 1)/2]^(1/(gamma-1))
```

Osher、Whitlow 与 Hafez, NASA TM-85751：

- 印刷页 22，方程 (4.1)–(4.3)：定义声速阈值和 E-O 质量通量偏置。
- 印刷页 28，密度偏置比较式（该比较式未编号）：对假设正向的 streamwise 差分定义
  `bar_rho_(j+1,k)=rho_(j+1,k)-nu_(j,k)(rho_(j+1,k)-rho_(j,k))`，
  `nu_(j,k)=max(0,1-1/Mtilde_(j,k)^2)`；文中只称 `Mtilde` 为局部马赫数的某种表示，没有指定唯一重构方式。
- 印刷页 29，未编号对比式：给出相应流向差分形式及其与 E-O 形式在光滑区相差 `O((Delta x delta_x q)^2)` 的比较；这是所写差分条件下的局部比较，不是任意 FV 网格上的恒等式。
- 印刷页 38–40，方程 (6.1)、(6.2)：一般坐标的守恒变换及通量偏置写法。原文 `J=det(d(xi)/d(x))` 是逆 Jacobian；`U_i=sum_j a_ij phi_(x_j)` 是未含行列式的 contravariant 分量，故变换后通量写作 `rho U_i/J`。本协议采用正向 `J_phys=det(d(x)/d(xi))=1/J`，对应通量 `J_phys rho U_i`。

密度偏置与 E-O 通量不是同一个数值通量。TM-85751 的熵证明以满足 E-flux 条件的通量为对象；论文对密度偏置给出比较，但不能据此推断任意二维密度上风 FV 实现自动满足熵条件。若下述验收不能建立所需离散熵性质，该密度偏置路线不得进入跨声速主求解器。

## 离散对象与度量

未来试验网格须为固定、结构化、光滑、正向映射的二维贴体网格 `(xi,eta)->(x,y)`。流向索引 `i` 沿局部主流连续排列，`j` 为横向。明确保存并逐单元检查

```text
J_phys = det[d(x,y)/d(xi,eta)] > 0
U_xi   = grad_x(xi)  dot grad_x(phi)
U_eta  = grad_x(eta) dot grad_x(phi)
F_xi   = J_phys rho U_xi
F_eta  = J_phys rho U_eta
```

`U_xi/U_eta` 是不含 Jacobian 的 contravariant 分量；`F_xi/F_eta` 才是乘了 Jacobian 的守恒通量密度。有限面通量还须乘计算面长度或直接使用物理有向面向量 `S_f=n_f Delta s_f`：

```text
F_f = rho_f * grad_x(phi)_f dot S_f
    = rho_f * J_phys * U_coord,f * Delta(other coordinate)
```

同一内部面只计算一次，左右残差使用严格相反符号。网格度量必须满足离散 metric identity（常势/均匀流自由流残差随网格精度降至舍入误差），不能在 cell divergence、面度量和 `J_phys` 中重复乘或漏乘 Jacobian。数值报告并行输出原始 `U_coord`、`J_phys U_coord`、`rho_f` 和面积积分通量，以便独立审计。

## 两个离散版本，不混称

### 原文差分基线

在笛卡尔、正向流向差分基线中先逐字实现印刷页 28 的密度偏置比较式：

```text
bar_rho_(i+1,j) = rho_(i+1,j)
                  - nu_(i,j) [rho_(i+1,j)-rho_(i,j)]
nu_(i,j) = max(0, 1 - 1/Mtilde_(i,j)^2)
```

通量算子和 `Mtilde` 重构必须按所选原始差分文献完整定义；TM-85751 本身将 `Mtilde` 留作“local Mach number 的某种表示”，故试验前必须显式声明并做敏感性分支，不得说它是原文唯一规定。正向差分假设失效时，按局部流向反转上/下游索引；跨越流向停滞点时不得用一个固定全局方向强行偏置。

作者称 E-O 与密度偏置在亚声速光滑区的相应二阶差分等价至截断项 `O((Delta x delta_x q)^2)`，但两者在超声速区不同。必须保留原文的 stencil，先在一维光滑制造解上确认二阶收敛和偏置项为零；不得把这条渐近比较直接当成二维 FV 等价证明。

### 候选共享面有限体积版本

FV 转换另立候选，不称其为论文原式。以面两侧重构密度 `rho_L,rho_R` 和面 contravariant 流向速度 `U_xi,f` 构造候选

```text
rho_center = (rho_L+rho_R)/2
nu_f = max(0, 1 - 1/Mtilde_f^2)
rho_f = rho_center - (nu_f/2) sign(U_xi,f) (rho_R-rho_L)
F_f = rho_f * grad_x(phi)_f dot S_f
```

该面插值在 `nu_f=0` 时退化为对称中心密度，在 `nu_f>0` 时沿 `U_xi,f` 加偏置，系数随 `nu_f` 增长而向上游密度移动。它只借用原文 `nu` 传感器的形状，不等于印刷页 28 的 `rho_d-nu(rho_d-rho_u)`，也不等于 E-O 通量；面定位、中心重构、偏置权重、面 Mach 数和 FV 度量耦合都是待验证的新决定。`Mtilde_f` 首选物理面状态重构的总局部 Mach；另对法向 Mach或单元中心 Mach定义做独立对照，不能混用结果。

`nu_f=0` 时偏置修正严格为零，禁止额外加人工黏性/迎风项；这就是候选 FV 版本的“无耗散亚声速极限”定义，光滑区剩余误差只能来自中心离散截断误差。原文差分式在 `nu=0` 时的节点密度定位不等于这里的中心面密度；若要声称复现原文，必须另外证明该节点 stencil 到 FV 面积分的等价，不能这样命名。横向通量先用对称二阶重构，不加该流向偏置；只有另有特征方向和熵论证后才可扩展。

这一 FV 版本要对每条内部面使用一个含 `J_phys` 的有向共享通量。其有限体积残差为

```text
R_cell = sum_faces F_face
F_face = rho_face * grad_x(phi)_face dot S_face
```

流向密度偏置只改变 `rho_face`，不改面面积向量、势梯度符号、质量通量定义或相邻单元的正负号。

## 熵与稳定性门槛

每个离散版本进入二维跨声速案例前，按顺序满足以下条件：

1. 一维均匀网格上压缩 shock 和反向 expansion Riemann 测试；记录质量余额、区间有界、激波/扇误差和 fully-discrete 二次熵不等式。`potential/entropy_riemann.py` 的 E-O 结果只认证 E-O 标量通量；密度偏置必须独立重测。
2. 笛卡尔二维旋涡-free 制造解和斜向弱激波：验证流向旋转/网格旋转不会改变熵选择，横向通量不产生额外熵源。
3. 每一方向/面态建立与残差符号一致的数值 E-flux/熵通量不等式。若解析证明无法给出，逐时步逐单元计算离散熵变化、数值熵通量散度及其最大正违反量；发现违反即失败，禁止通过翻转熵通量号或加未声明耗散掩盖。
4. 跨声速翼型网格上记录 sonic line、激波两侧状态、每面质量通量、全域质量余额、熵残差、Bernoulli 正性和不同初值/网格的解分支。弱激波全势结果只能作为等熵模型解，不解释为真实激波后的热力学熵增。

熵验收失败时可回退到有清楚 E-flux 依据的 E-O 通量或停止跨声速路线；不能因为密度上风方案收敛或曲线平滑，就称其满足物理解条件。对强激波/分离，全势模型仍在物理适用边界之外。

## 二维验收与准入

- **自由流/亚声速：** 对常势和解析光滑解做网格加密；`nu_f` 必须处处为零（按设定阈值），流向偏置增量严格为零；质量守恒、二阶 L1/Linf 收敛和压力误差满足事先登记的阈值。
- **通量方向：** 对正、反向局部 `U_xi` 分别验证上游选择；物理坐标/计算坐标方向翻转后解等价，不能用正向索引偏置负向流。
- **Jacobian/metric：** 常势自由流离散残差、解析网格度量和面有向面积闭合通过；独立计算 `J_phys` 与逆 Jacobian 乘积，要求 `|J_phys J_inv-1|` 在预定舍入容差内。
- **一维退化：** 二维单元沿 `eta` 常值复制时，残差逐点退化到已测试的一维对应方案；否则停止。
- **压缩与膨胀：** 稳态压缩 shock 符合 RH/质量守恒；以反向膨胀跳跃初始化不得保留为稳定解，必须满足离散熵条件。
- **跨声速翼型：** 至少两层以上系统网格加密；比较压力系数、shock 位置/强度、质量余额、最大熵违反、迭代终止原因和初值分支。各误差限须在运行前写入独立 case 配置；未达阈值或熵失败即 `FAIL`。

只有上述各关卡均通过，才可提出独立的二维 solver implementation PR。此协议本身、1D E-O 测试通过或 NASA 文献中报告的算例，均不代表本项目已经具备二维跨声速求解能力。
